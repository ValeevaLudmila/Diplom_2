# 🌌 Stellar Burgers API Testing

Автоматизированное тестирование REST API космической бургерной **Stellar Burgers**.
Проект покрывает критические сценарии создания пользователей, логина и оформления заказов с помощью **pytest**, **requests** и **Allure Reports**.

---

## 🎯 Цели проекта

* Проверка эндпоинтов API на корректность работы.
* Обеспечение стабильности пользовательских сценариев:

  * Создание уникального и уже зарегистрированного пользователя.
  * Вход в систему с корректными и некорректными данными.
  * Создание заказа с ингредиентами, без них, с авторизацией и без.
* Ведение подробной визуальной отчётности через Allure.

---

## 🛠 Технологии

* **Python 3.x**
* **pytest** — фреймворк для тестирования
* **requests** — работа с HTTP-запросами
* **Allure Pytest** — красивые отчёты
* **Faker** — генерация тестовых данных

---

## 📂 Структура проекта

```
stellar-burgers/
├─ tests/
│  ├─ test_create_user.py      # Тесты регистрации пользователя
│  ├─ test_login_user.py       # Тесты логина
│  ├─ test_create_order.py     # Тесты создания заказов
│  └─ conftest.py              # Фикстуры для пользователей и токенов
├─ data.py                     # Статусы, шаблоны ответов, тестовые данные
├─ urls.py                     # API эндпоинты
├─ generators.py               # Генерация email, имени и пароля
└─ requirements.txt            # Список зависимостей
```

---

## ⚡ Быстрый старт

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Запустить все тесты:

```bash
pytest -v
```

3. Создать Allure отчет:

```bash
pytest --alluredir=allure-results
allure serve allure-results
```

---

## ✅ Покрытие тестами

| Эндпоинт                | Сценарии                                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------------------------ |
| **POST /auth/register** | Создание уникального пользователя, ошибка при существующем пользователе, отсутствие обязательного поля |
| **POST /auth/login**    | Логин существующего пользователя, неверные данные, отсутствие поля                                     |
| **POST /orders**        | Создание заказа с/без авторизации, с ингредиентами, без ингредиентов, с неверным хешем                 |

---

## 💡 Особенности

* Полная генерация уникальных пользователей для каждого теста через Faker.
* Мокирование и фикстуры позволяют безопасно создавать и удалять тестовые данные.
* Пошаговая визуализация всех действий в Allure.
* Параметризация тестов — проверка нескольких сценариев за один запуск.
